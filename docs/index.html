Install root
%LOCALAPPDATA%\VolumeControl

Per-user only. The bootstrap refuses any other location — no elevation, no Program Files.

Config survives
%APPDATA%\volume-control\config.ini

Lives outside the install root: update and uninstall preserve your hotkeys and settings.

Update rule
-Action update

Refuses to run while VolumeControl is open. It never force-terminates your process — close the app first.

What verification does — and does not — prove

Trust boundaries, stated plainly

  • Checksums, not signatures. SHA256SUMS.txt proves a download matches the release it was published with — same-release integrity only. It is not code signing and says nothing about who built the binary.
  • Releases are unsigned. Windows SmartScreen may warn on first run of VolumeControl_<version>_x64-setup.exe; that warning is expected until an Authenticode certificate is added.
  • No pipes into a shell. Every command above downloads first, verifies SHA-256, then executes the local copy from a fresh temporary folder — downloaded text never runs while it arrives.
  • Immutable releases. Published assets are never overwritten; re-uploading an existing tag fails instead of mutating bytes.
